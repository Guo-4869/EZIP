# EZip 隐私政策

**生效日期：2026-10-19　　适用版本：EZip 1.0.7 及以后**

EZip（以下简称"本应用"）是一个免费、开源的 Android 压缩/解压工具。本政策说明本应用如何处理你的信息。

## 一句话说明

**本应用不联网、不需要注册、不收集任何个人信息，你的文件、密码和操作记录都不会离开你的手机。**

## 1. 我们收集哪些信息

**不收集任何信息。**

本应用：

- 没有账号体系，不需要登录；
- 没有统计、埋点、广告、崩溃上报等任何第三方 SDK；
- **没有申请网络权限（android.permission.INTERNET）**，因此在系统层面就无法向任何服务器发送数据；
- 不读取设备标识符（IMEI、Android ID、MAC 等）、不读取位置、通讯录、短信、通话记录、相机、麦克风。

## 2. 本应用会访问哪些内容，为什么

| 访问的内容 | 用途 | 是否必需 |
| --- | --- | --- |
| 你手机上的文件与文件夹 | 浏览目录、显示文件列表 | 是（核心功能） |
| 你选择的文件 | 打包成压缩包、读取压缩包内容 | 是 |
| 你指定的目标文件夹 | 写入压缩包 / 解压出来的文件 | 是 |
| 压缩包密码（如你输入） | 仅用于本次加密或解密 | 否（不加密时不会涉及） |

为实现上述功能，本应用需要「所有文件访问权限」（Android 11+ 的 `MANAGE_EXTERNAL_STORAGE`）。
该权限**只用于你主动操作的目录和文件**，本应用不会扫描、索引或上传你的文件。

你可以随时在「设置 → 应用 → EZip → 权限」中撤销该权限；撤销后本应用只能在自身私有目录内工作。

## 3. 你的数据存放在哪里

- 压缩包、解压结果：写入**你自己指定的目录**（默认是当前浏览的文件夹）；
- 预览用的临时文件：存放在应用缓存目录（`Android/data/com.ezip.app/cache`），系统可随时清理；
- 应用设置（如排序方式、是否显示隐藏文件）：仅保存在本机，卸载即删除。

**本应用不会把上述任何数据复制到服务器或第三方。**

## 4. 密码如何处理

你输入的压缩包密码：

- 只存在于本次操作的运行内存中；
- **不会保存到磁盘、不会写入日志、不会上传**；
- 关闭应用或操作结束后即释放。

## 5. 权限说明汇总

| 权限 | 用途 |
| --- | --- |
| `MANAGE_EXTERNAL_STORAGE` | 浏览与读写手机存储中的文件（压缩/解压所必需） |
| `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE` | 兼容版（Android 10 及以下）读写存储 |
| `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO` / `READ_MEDIA_AUDIO` | 兼容版在 Android 13+ 读取媒体文件 |

本应用**不申请**：网络、定位、通讯录、短信、相机、麦克风、电话状态、读取已安装应用列表等权限。

## 6. 第三方组件

本应用使用了若干开源库（zip4j、junrar、Apache Commons Compress、XZ for Java、SLF4J）用于压缩/解压运算。
这些库**只在本机参与计算**，不含网络通信、不含统计或广告功能。完整清单与许可证见项目 `README.md`。

## 7. 儿童隐私

本应用不收集任何个人信息，因此也不会收集儿童的个人信息。

## 8. 你的权利

由于本应用不收集、不存储、不上传任何个人信息，不存在"查询/更正/删除个人信息"的流程：

- 想删除全部数据：在系统里卸载本应用即可（应用私有目录随之删除）；
- 想撤销权限：设置 → 应用 → EZip → 权限。

## 9. 政策变更

如未来版本新增需要联网或收集数据的功能，本政策会同步更新，并在应用内明确提示、征得你的同意后才会启用。

## 10. 联系方式

本项目为开源项目，问题与建议请通过代码仓库的 Issues 反馈。

---

### 附：可自行核验的三件事

1. **看权限**：设置 → 应用 → EZip → 权限，只有"存储/文件"相关项，没有网络。
2. **看流量**：手机流量统计里，本应用的数据使用量恒为 0（无 INTERNET 权限，系统禁止其联网）。
3. **看源码**：项目为开源，可自行检查 `AndroidManifest.xml`（权限声明）与全部 Java 源码。
